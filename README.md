# SteamSNM

**Steam Notifier & Monitor** — десктопный клиент для мониторинга Steam под Linux.
Работает как самодостаточный **AppImage**, интерфейс на PySide6 (Qt).

> SteamSNM — независимый проект. Он **не является** продуктом Valve или SteamDB
> и не парсит сайт SteamDB. Все данные берутся из официальных публичных
> Steam Store API и Steam Web API.

## Возможности

- **Весь каталог Steam сразу при запуске** — ничего добавлять не нужно: клиент
  сам подгружает тысячи игр страницами по 100 (поиск Steam `search/results`),
  кэширует список в `catalog.json` и показывает его мгновенно при следующих запусках.
  Плюс подборки «Скидки», «Лидеры продаж», «Популярные», «Новинки» и «Скоро»
  с ценами и скидками.
- **Зарубежные игры** — полный каталог грузится из глобального поиска Steam
  (США/английский), поэтому в списке есть и игры, недоступные в выбранном регионе.
  Отдельный фильтр «Зарубежные» показывает именно их.
- **Иконки и страницы игр** — обложки в списке. Двойной клик по игре (или кнопка
  «Страница игры») открывает страницу **внутри главного окна** с баннером,
  описанием, жанрами, датой выхода, разработчиком, ценой, скидкой, онлайном,
  рейтингом и скриншотами. Каждая следующая страница открывается поверх прошлой,
  кнопка «← Назад» возвращает к предыдущей странице или к списку игр.
- **Отслеживание и уведомления** — кнопка «☆ Отслеживать» на странице игры добавляет
  её в список; фоновая проверка присылает в трей уведомления о новых/увеличенных
  скидках, снижении цены, целевой цене и бесплатном переходе. Фильтр
  «Отслеживаемые» показывает весь список.
- **Цены и скидки** — текущая/старая цена, процент скидки, локальная история цен
  с графиком. Для игр из общего каталога цена подгружается при открытии страницы.
- **Онлайн по запросу** — число игроков обновляется кнопкой «Обновить онлайн».
- **Дополнительно**:
  - пагинация (100 игр на страницу), поиск, фильтры и сортировка таблицы;
  - график истории цен, целевая цена для отслеживаемой игры;
  - сводка «Найдено / Со скидкой» и прогресс загрузки каталога;
  - журнал событий, тёмная тема оформления в стиле Steam;
  - открытие страницы игры в Steam;
  - **смена валюты** (RUB по умолчанию, 14 валют) прямо в настройках — цены
    перезагружаются из Steam в выбранной валюте; история цен сбрасывается, чтобы
    не смешивать разные валюты;
  - настройка интервала опроса, автозапуска и сворачивания в трей;
  - запуск в единственном экземпляре.

## Запуск

```bash
chmod +x SteamSNM-x86_64.AppImage
./SteamSNM-x86_64.AppImage
```

Если FUSE недоступен:

```bash
./SteamSNM-x86_64.AppImage --appimage-extract-and-run
```

Данные и настройки хранятся в `~/.config/SteamSNM`:

- `settings.json` — настройки;
- `watchlist.json` — отслеживаемые игры;
- `catalog_global.json` — кэш полного (глобального) каталога Steam;
- `history.sqlite3` — история цен, состояния игр и база уведомлений.

## Сборка из исходников

Нужны: Python 3.10+, PySide6, `appimagetool`, Linux x86_64.

```bash
python3 -m pip install PySide6 pillow
# скачать appimagetool-x86_64.AppImage, например:
# curl -L -o /tmp/appimagetool.AppImage \
#   https://github.com/AppImage/AppImageKit/releases/download/continuous/appimagetool-x86_64.AppImage
./build_appimage.sh /tmp/appimagetool.AppImage
```

Сборщик (`tools/build_appimage.py`) копирует интерпретатор Python, stdlib,
PySide6, библиотеки Qt и плагины в `build/AppDir`, затем упаковывает его через
`appimagetool`. Готовый файл — `SteamSNM-x86_64.AppImage`.

Для запуска без сборки (из исходников, с системным Python):

```bash
python3 src/main.py
```

## Используемые API

| Назначение | Endpoint |
|---|---|
| Информация об игре и цене | `store.steampowered.com/api/appdetails` |
| Поиск игр | `store.steampowered.com/api/storesearch` |
| Онлайн игроков | `api.steampowered.com/ISteamUserStats/GetNumberOfCurrentPlayers/v1` |
| Скидки/новинки | `store.steampowered.com/api/featuredcategories` |

Ограничения Steam: `appdetails` принимает только по одному `appid` за запрос,
поэтому опрос идёт последовательно с небольшой задержкой. Некоторые игры могут
быть недоступны в выбранном регионе — они остаются в списке с пометкой
«Нет данных для региона».

## Структура

```
src/
  main.py               точка входа, единственный экземпляр приложения
  steam_api.py          обёртка над Steam API
  storage.py            JSON-настройки/список + SQLite-история
  monitor.py            фоновый опрос и генерация уведомлений
  ui/main_window.py     главное окно, таблица, график, трей
  ui/dialogs.py         настройки, добавление игры, «О программе»
  resources/            иконка и AppStream-метаданные
tools/                  генератор иконки и сборщик AppImage
```
